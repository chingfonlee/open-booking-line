# Ep03-3 — Farmer Booking Flow (農友申請流程與防護)

## Goal (目標)
農友端僅能提出寬鬆偏好時段（上午 / 下午 / 都可以），嚴禁提供精確時間選擇器。

---

## 核心規格要求
1. **介面時段限制**：
   - 僅提供：`上午`、`下午`、`都可以`。
   - 嚴格禁止出現 `08:00`, `08:30`, `09:00` 等確切時間選擇元件。
2. **免責與預約說明提示**：
   - 介面清楚註明：*「此為希望服務時段，實際服務日期與開工時間將由服務站聯絡確認。」*
3. **送單重驗證防護 (Submit Validation)**：
   - 後端接收預約申請時，必須重新校驗日期、時段可用性、封鎖狀態與預約前置時間（Lead Time / Booking Horizon）。
   - 若送單當下該時段已被正式確認占用，必須拒絕並提示更新時段。
   - 保留 `date_flexibility` 欄位供管理員後續協調。
