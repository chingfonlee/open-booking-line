## 如何對應影片與程式碼版本

每支影片對應一個 Git Tag。要取得特定影片使用的程式碼版本：

```bash
# 取得 Episode 01 的程式碼
git checkout v1.0.1

# 取得 Episode 02 的程式碼（發布後）
git checkout v0.2-rich-menu
```
